# Sunrise Dental Clinic Appointment and Patient Management System

A complete, working university student-level software engineering project for **Sunrise Dental Clinic, Colombo**, developed with pure Java and vanilla web technologies without using any third-party application frameworks.

The complete application is organized inside the `SunriseDentalClinic/` folder:

```text
SunriseDentalClinic/
├── backend/
└── frontend/
```

For full documentation, architecture diagrams, installation instructions, and viva explanation, please see [SunriseDentalClinic/README.md](file:///SunriseDentalClinic/README.md).

## Quick Start (Windows)

To start the system:
1. Double-click or run `SunriseDentalClinic\run-system.bat`
2. Open your browser to `http://localhost:8080`
3. Login using:
   * **Username**: `admin`
   * **Password**: `Admin@123`

To run the automated JUnit tests:
```cmd
cd SunriseDentalClinic\backend
test.bat
```
